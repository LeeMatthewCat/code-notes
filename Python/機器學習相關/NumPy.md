# array\(\) 陣列

和**串列**比起來，陣列在**儲存數據時更加緊密**、運算**速度更快**

## 陣列基本

```Python
import numpy as np
```

在 NumPy 中，維度被稱為**軸 \(Axes\)**：

- **1D 陣列 \(Vector / ****向量****\)**：像是**一條線上**的數據集合

- **2D 陣列 \(Matrix / ****矩陣****\)**：具有行 \(Row\) 與列 \(Column\) 的**表格數據**，是最常見的格式（例如 **CSV 數據**、灰階圖片）

- **3D 陣列 \(Tensor / 張量\)**：由**多個 2D 陣列堆疊**而成，常見於彩色圖片 \(RGB 三個通道\) 或影片數據

```Python
import numpy as np

# 從串列轉換
arr_1d = np.array([1, 2, 3])
arr_2d = np.array([[1, 2, 3], 
                    [4, 5, 6]]) # 分行方便閱讀
arr_3d = np.array([[[1,2],[3,4]],
                    [[5,6],[7,8]]])

# 直接建立特殊形式
print(np.zeros((2, 3))) # 建立 2x3（先直再橫）的全 0 陣列
print(np.ones((3, 3))) # 建立 3x3 的全 1 陣列
print(np.arange(0, 10, 2))  # (起始, 結束 --> 要小於他, 步長)
print(np.linspace(1, 100, num=50, endpoint=True)) # 1~100 自動間距取出 50 個，最後一個參數為設定含尾
print(np.linspace(0, 1, 5)) # 在 0 到 1 之間平均取 5 個數：[0.  0.25 0.5  0.75 1. ]
print(np.full((2, 3), 7)) # 2*3 裡面都是 7
print(np.random.random((2, 3))) # 2*3 從 0~1 的隨機浮點數
print(np.random.randint(1, 7, size=5)) # 1~7 隨機取 5 個整數
print(np.random.randn(3)) # 3 個常態分布數值（平均值為 0、標準差為 1 的亂數，通常在 -1~1 之間，偶爾出現極端值）
```

- 屬性：

    **\.ndim**：陣列的維度數量（例如 1, 2, 3）

    **\.shape**：陣列的形狀（例如 \(2, 3\) 代表 2 列 3 行）

    **\.size**：陣列中元素的總數（例如 2x3 的陣列，size 就是 6）

    **\.dtype**：陣列中元素的資料型別，而陣列中元素的型別必須一致

## 陣列運算

像一般數字一樣進行四則運算

```Python
print(np.array([1, 2, 3]) * np.array([4, 5, 6]))
# [ 4 10 18]
```

若形狀不同時，利用**廣播機制（Broadcasting）**將較小的擴充（填入同樣的）進行運算

```Python
print(np.array([1,3,5,7]) * np.array([[2,4,6,8], 
                                    [10,12,14,16]])) 

# [[  2  12  30  56]
# [ 10  36  70 112]]

# 相當於 [[1,3,5,7], [1,3,5,7]] * [[2,4,6,8], [10,12,14,16]]
```

**其他常用的運算函數：**

> 四捨五入後仍會留下小數點，因為 NumPy 設計概念上只改變數值，不隨便改變資料別
> 
> 而內建的四捨五入則不同，會改變型別：
> 
> ```Python
> a = 3.5
> b = round(a)
> 
> print(type(a)) # <class 'float'>
> print(type(b)) # <class 'int'>
> ```

```Python
print(np.round(np.array([1.5, 2.4, 3.8]))) # 四捨五入到整數位（預設）
# [0. 0. 0.]

print(np.round(np.array([1.24567, 2.45637, 3.827892]), decimals=2)) # 自訂位數
# [1.25 2.46 3.83]

print(np.array([1, 2, 3, 4])) # 計算平方

print(np.array([0, 1, 2])) # 計算 e^x（尤拉數的次方）

print(np.pi) # 呼叫圓周率

print(np.deg2rad([0, 90, 180])) # 角度轉弧度
print(np.rad2deg([0, np.pi/2])) # 弧度轉角度

print(np.sin(np.array([0, np.pi/2, np.pi]))) # 三角函數運算（其他三角函數同理）（用弧度計算）
```

## 矩陣

### transpose\(\) 矩陣轉置

用二維來表示矩陣（matrix）

轉置（Transpose）指的是將矩陣的行列調換

![截圖 2026\-04\-23 晚上8\.07\.32\.png](圖片/截圖%202026-04-23%20晚上8.07.32.png)

```Python
print(np.array([[1,2,3],[4,5,6]]))
# [[1 2 3]
#  [4 5 6]]

print(np.transpose([[1,2,3], 
                    [4,5,6]]))
print(np.array([[1,2,3], 
                [4,5,6]]).T) # 直接 .T，同意思
# [[1 4]
#  [2 5]
#  [3 6]]
```

> 一維陣列無法轉置

---

### 矩陣乘法

不用 \* ，而是用 **@** 表示

```Python
print(np.array([[1,2], 
                [3,4]]) @ np.array([[1,2], 
                                    [3,4]]))
# [[ 7 10]
#  [15 22]]
```

## meshgrid\(\) 轉換網格座標

和 Matplot 繪製立體圖有關

使 a 個元素和 b 個元素的一維陣列變為二維 b\*a 矩陣

```Python
w = [1, 2, 3] # x 軸資料
b= [10, 20] # y 軸資料

W, B = np.meshgrid(w, b)
```

$w=\begin{bmatrix}
  1& 2 & 3\\
  1& 2 & 3
\end{bmatrix}$，$b=\begin{bmatrix}
  10& 10 & 10\\
  20& 20 & 20
\end{bmatrix}$

使其產生 6 個點

> \(1,10\)、\(1,20\)、\(2,10\)、\(2,20\)、\(3,10\)、\(3,20\)
